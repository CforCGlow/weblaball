# SEU Tech Summit 2026 — Workshop Registration System

Real-world student workshop registration website built progressively across 5 stages:
HTML structure → CSS styling → JavaScript interaction → Form validation + JSON + localStorage → Fetch + API.

## Structure
```
labs/
  lab-01-html/            HTML structure only
  lab-02-css/             + styling (css/style.css)
  lab-03-javascript/      + interaction (js/script.js)
  lab-04-forms-json/      + validation, JSON, localStorage
  lab-05-fetch-api/       + data/workshop.json, Fetch, public API
```

## Run
- Lab 01–04: open `index.html` in browser.
- Lab 05: open folder in VS Code → Open with Live Server (fetch requires http).

## Stack
HTML5, CSS3, Vanilla JavaScript. No frameworks.
