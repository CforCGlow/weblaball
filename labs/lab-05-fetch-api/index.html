About the Event

Welcome to the SEU Tech Summit 2026. The primary goal is hands-on problem solving, modern web development and innovation among undergraduates.

Participants join coding sprints, project showcases and mentoring sessions with engineers and faculty.

Venue & Contact

Auditorium & Computer Labs, Southeast University, 251/A Tejgaon I/A, Dhaka-1208.
